# Screenshots

The README files reference two images from this directory:

| File | What it should show |
| --- | --- |
| `panel.png` | The calendar panel open in the Web GUI: sidebar entry highlighted, four stat cards, the full 53-week grid, a few months of real activity |
| `tooltip.png` | A close-up of one day hovered under the **Tokens** metric, with the `in · out · cached` breakdown visible |

## How to take them

1. Install and restart DeepSeek Harness so the plugin is active.
2. Open **Conversation calendar** in the sidebar.
3. Use a window roughly 1200 px wide for a tidy 53-column grid.
4. Capture the window (macOS `⇧⌘4` then `Space`, Windows `Win+Shift+S`), trim the
   browser chrome, and save as PNG at exactly these names.

Light or dark theme both work — the panel follows the DSH theme variables, so a single
pair of screenshots is enough.

## Tips

- Prefer a screenshot that shows real activity (several shaded weeks) over an empty grid.
- Keep the file size modest (under ~400 KB); PNG at 1× or 2× scale is fine.
- If you add a GIF or video, put it beside these files and link it from both READMEs.
